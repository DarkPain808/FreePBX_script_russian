Это скрипт установки FreePBX 17.

__Что изменено в сравнении с официальным скриптом:__
1. Репозиторий изменен на русское зеркало.
2. Все комментарии на РУССКОМ языке, для обучения работы Bash.

__Необходимо для установки:__
- системы Debian 12.x

__Использование скрипта установки__

Скачайте файл, используя wget:
```bash
wget https://github.com/DarkPain808/FreePBX_script_russian/blob/main/freepbx_debian_12.sh -O /tmp/freepbx_debian_12.sh
```

Выполните скрипт:
```
bash /tmp/freepbx_debian_12.sh
```


__Аргументы, которые скрипт может принимать__

Обратите внимание на ДВА символа '--'.

1. ```--dahdi``` - Данный аргумент используется при установке FreePBX с поддержкой DAHDI, необходимой для карт Sangoma. Рекомендуется использовать его, если вы планируете использовать FreePBX с цифровыми или аналоговыми картами Sangoma. Этот параметр также загрузит необходимые драйверы wanpipe и DAHDI.
2. ```--testing``` - Полезен при тестировании репозитория «development» или «testing». Мы управляем двумя репозиториями Debian: «production» и «development/testing». Сначала мы отправляем любые новые или обновленные пакеты в репозиторий «development/testing», чтобы убедиться, что они не вызывают проблем, прежде чем перемещать их в репозиторий «production».
3. ```--nofreepbx``` - Используйте, если вы не хотите устанавливать пакет Freepbx, а просто хотите выполнить начальную настройку Freepbx.
4. ```--noasterisk``` - Используйте, если вы не хотите устанавливать пакет Asterisk и предпочитаете использовать свой собственный Asterisk.
5. ```--dahdi-only``` - Данный аргумент используется для установки поддержки DAHDI в системе, в которой DAHDI уже установлен и настроен.
6. ```--skipversion``` - Данный скрипт включает логику для проверки того, является ли версия скрипта установки на GitHub более новой, чем версия скрипта, запущенного в данный момент. Если версия на GitHub новее, выполнение скрипта завершится неудачей. Существует опция для обхода этой проверки версии, но её использование не рекомендуется.
7. ```--opensourceonly``` - Данный аргумент позволит скрипту устанавливать только модули FreePBX с открытым исходным кодом.
