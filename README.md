Это скрипт установки FreePBX 17.
Все комментарии на РУССКОМ языке. Создан для обучения работы Bash.

Необходимо для установки:
- системы Debian 12.x

Скачайте файл, используя wget:
wget https://github.com/DarkPain808/FreePBX-/blob/main/freepbx_debian_12.sh -O /tmp/freepbx_debian_12.sh


Выполните скрипт:
bash /tmp/sng_freepbx_debian_install.sh
