Это скрипт установки FreePBX 17.

__Что изменено в сравнении с официальным скриптом:__
1. Репозиторий изменен на русское зеркало.
2. Все комментарии на РУССКОМ языке, для обучения работы Bash.

__Необходимо для установки:__
- системы Debian 12.x

Скачайте файл, используя wget:
```bash
wget https://github.com/DarkPain808/FreePBX_script_russian/blob/main/freepbx_debian_12.sh -O /tmp/freepbx_debian_12.sh
```

Выполните скрипт:
```bash
bash /tmp/sng_freepbx_debian_install.sh
```



**Использование скрипта установки**
Скрипт установки принимает следующие аргументы — 
обратите внимание на ДВА символа '--'.

--dahdi
 Этот параметр используется при установке FreePBX с поддержкой DAHDI, необходимой для карт Sangoma. Рекомендуется использовать его, если вы планируете использовать FreePBX с цифровыми или аналоговыми картами Sangoma. Этот параметр также загрузит необходимые драйверы wanpipe и DAHDI.

--testing
 Это полезно при тестировании репозитория «development» или «testing». Мы управляем двумя репозиториями Debian: «production» и «development/testing». Сначала мы отправляем любые новые или обновленные пакеты в репозиторий «development/testing», чтобы убедиться, что они не вызывают проблем, прежде чем перемещать их в репозиторий «production».

--nofreepbx
 Это полезно, если вы не хотите устанавливать пакет Freepbx, а просто хотите выполнить начальную настройку Freepbx.

--noasterisk
 Это полезно, если вы не хотите устанавливать пакет Asterisk и предпочитаете использовать свой собственный Asterisk.

--dahdi-only
 Эта опция используется для установки поддержки DAHDI в системе, в которой DAHDI уже установлен и настроен.

--skipversion
 Этот скрипт включает логику для проверки того, является ли версия скрипта установки на GitHub более новой, чем версия скрипта, запущенного в данный момент. Если версия на GitHub новее, выполнение скрипта завершится неудачей. Существует опция для обхода этой проверки версии, но её использование не рекомендуется.

--opensourceonly 
Эта опция позволит скрипту устанавливать только модули FreePBX с открытым исходным кодом.
